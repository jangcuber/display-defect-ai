# 데이터 생성 → 모델 학습 인계

## 실행

저장소 루트, Python 3.10 이상(검증 환경 3.12.14):

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements/generation.txt
.venv/bin/python scripts/generate_dataset.py --output data/pilot-v1
.venv/bin/python scripts/check_dataset.py data/pilot-v1
.venv/bin/python scripts/check.py
```

이미 존재하는 출력 폴더는 덮어쓰지 않습니다. 재실행은 `--output data/pilot-v2`처럼 새 경로를 사용합니다.
표시할 이미지는 `--content /path/to/content.png`로 지정합니다. 기본값은 회색 180 화면입니다.
`--cases 30 --variants 2 --size 512 --seed 42`가 기본값입니다. 각 사례마다 정상/점/선을 생성합니다.
맥에서도 같은 명령을 사용하며 GUI 의존성이 없는 OpenCV headless를 설치합니다.

## 생성 모델

내용 이미지 → 사례별 패널 밝기/색감/완만한 밝기 편차 → 결함 주입 → 원근/흐림/노이즈 → PNG.
점은 밝거나 어두운 원, 선은 밝거나 어두운 수평/수직선 한 개입니다. 정상에는 결함이 없습니다.
같은 사례/변형 번호의 세 종류는 동일한 촬영 조건을 공유합니다. 결함 위치 마스크로 박스를 계산합니다.
AI 생성은 사용하지 않습니다. 프로그램이 결함을 통제하므로 정확한 자동 라벨을 만들기 쉽습니다.

원본 사례는 가상의 패널 한 개입니다. 30개 사례를 먼저 21/4/5개로 분리하고 각 사례의 모든 변형·종류를
같은 분할에 넣습니다. 표시 콘텐츠는 동일 화면 검사라는 목적상 모든 분할에서 공유합니다.
따라서 '미지의 콘텐츠에 대한 일반화' 시험은 아닙니다. 여러 실제 원본 사진/패널을 도입하면
물리 패널·촬영 세션·원본 사진을 묶은 영구 ID를 먼저 정하고 파생본 전체를 같은 분할에 넣어야 합니다.
데이터를 별도 실행으로 나눈 뒤 합치면 case ID가 재사용되므로 금지합니다.

## 결과와 형식

사용자 요청으로 최초 합성 묶음 `data/pilot-v1/`은 Git에 포함했습니다. 새 생성 데이터는 계속 gitignore 대상입니다.
맥에서 클론 후 `bash setup_mac.sh`로 의존성 설치·검증과 dataset.yaml의 로컬 절대 경로 설정을 수행하세요.
기존 묶음을 다시 생성할 필요는 없습니다.
YOLO 입력: `data/pilot-v1/dataset.yaml` (이동 시 절대 path 수정).
`images/`, `labels/`, `previews/`에 split별 파일이 있고, manifest.jsonl에 사례·조건,
generation.json에 seed/도구 버전/소요 시간이 있습니다. 상세 라벨 규격은 interface.md 참고.

클라우드 CPU에서 512×512 180장과 라벨·전체 미리보기 생성 약 4.55초(시작/의존성 설치 제외).
train 126장, val 24장, test 30장; 각 분할의 세 종류 수는 동일합니다.
검사기로 이미지 디코딩, 정상 빈 라벨, 클래스·박스 범위·픽셀 좌표 왕복, 파일 개수,
사례 분할 무중복을 확인했습니다. 정상·점·선 대표 미리보기를 시각 확인했습니다.
기존 통합 테스트는 39개 모두 통과, skip/expected failure 없음.

## 다음 작업과 한계

YOLO26n 학습은 아직 실행하지 않았습니다. 다음 세션에서 공식 구현·버전·가중치를 확인하고
작은 데이터 로딩/학습/추론을 먼저 검증하세요. 얇은 선·작은 점은 리사이즈로 사라질 수 있으므로
학습 입력 크기와 증강 후 라벨/가시성을 확인해야 합니다. OpenCV 규칙 비교 기준도 다음 작업입니다.

합성 영상은 반사·모아레·서브픽셀·센서·렌즈·불량의 물리 특성을 완전히 모사하지 않습니다.
실제 정상 사진과 결함 사례를 확보해 크기·대비·촬영 조건을 조정하고, 별도 실제 시험 자료로 평가해야 합니다.
현재 한 이미지당 결함 하나, 단순 배경, 사각 패널이며 복수 결함·복잡한 화면은 후속 확장입니다.
사각형이 존재해도 대비가 작은 배경에서는 결함이 안 보일 수 있습니다. 사용자 콘텐츠에서는 반드시
미리보기를 확인하세요. 현재 검사기는 구조를 검증하며 사람의 가시성 검토를 대체하지 않습니다.
