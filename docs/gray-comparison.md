# OLED 회색 화면 U-Net 시험

회색 48·96·144·192/255에서 정상과 불량을 짝으로 만든 3,360장과 픽셀 마스크를 사용했습니다. 같은 가상 패널에서 나온 네 밝기와 일곱 유형을 한 분할에 유지했습니다. 학습 2,352장, 검증 504장, 시험 504장입니다.

같은 패널의 네 밝기는 결함 위치·크기·채널별 출력 저하 비율을 공유합니다. 사진은 1024×1024 원본 타일을 저장합니다. 가장 어두운 조건에서도 최대 채널 차이 2 DN 이상인 픽셀이 생기도록 레시피 129건을 다시 뽑았습니다. 이 기준은 완전히 보이지 않는 결함을 시험에서 제외합니다. 픽셀 중복과 패널 누출은 0건입니다.

[같은 패널의 정상·불량·마스크 그림은 평가 자료 ZIP에서 확인할 수 있습니다.](https://github.com/jangcuber/display-defect-ai/releases/download/v0.4.0/DisplayDefectAI-evaluation.zip)

흰 화면 가중치에서 5 epoch 미세 조정했습니다. RGB 공통 이득으로 각 타일의 중앙 밝기를 맞췄으며 채널별 차이는 유지했습니다. 입력은 사진 한 장입니다. 동일 전처리의 초기 검증 Dice는 91.6%, 최고 체크포인트인 epoch 4는 96.2%입니다. 체크포인트와 후처리 임계값은 검증 자료로 결정했습니다.

시험은 5888×3368 전체 장면을 1024 타일로 나누어 처리했습니다. 같은 유형의 박스를 IoU ≥ 0.5로 일대일 대응했습니다. 재현율은 실제 불량 중 찾은 비율, 정밀도는 검출 결과 중 정답인 비율입니다.

회색 값은 합성 촬영 영상의 명목 디지털 값입니다. 패널 픽셀 1개는 합성 촬영 이미지 3픽셀에 해당합니다. 완전 검정, 네 단계 사이의 밝기 및 실제 카메라 촬영은 이번 시험 범위 밖입니다.

실행 순서는 데이터 생성, 데이터 검증, U-Net 학습, U-Net 평가, 보고서 생성입니다. 저장소 루트에서 실행합니다.

~~~bash
.venv/bin/python scripts/generate_oled_gray_dataset.py
.venv/bin/python scripts/check_oled_gray_dataset.py data/oled-gray-paired-v1
artifacts/yolo-env/bin/python scripts/train_oled_gray_unet.py
artifacts/yolo-env/bin/python scripts/evaluate_oled_gray_unet.py
artifacts/yolo-env/bin/python scripts/render_oled_gray_report.py
~~~
