# 한 달 개발 계획

리더가 전체 과정을 먼저 완성하고 팀원에게 실행 가능한 템플릿을 제공합니다.

| 기간 | 작업 | 완료 기준 |
|---|---|---|
| 1주 | 정상·점·선 생성, 라벨·분할 검증, 실제 정상 사진 조건 조사 | 작은 데이터, 사각형 미리보기, 생성 조건과 인계 |
| 2주 | OpenCV 규칙 비교 기준, 픽셀 마스크, U-Net·YOLO26n 학습 | 같은 분할·원본 해상도에서 비교, 버전·가중치 출처 기록 |
| 3주 | 맥 단일 사진 검사와 사진별 결과 종합 규칙 | 원본·박스·픽셀 출력·확대, 실패 안내, 검증 자료로 모델·임계값 결정 |
| 4주 | 고정 시험 평가·오류 분석·팀원 템플릿 | 클래스별 검출 지표, 사진별 오탐/미탐, 재현 명령 |

합성 시험 성적과 실제 사진 성적은 따로 보고합니다. 실제 시험 자료가 없으면 실제 성능은 미검증입니다.
YOLO26n 패키지·가중치와 두 모델의 Apple MPS 학습·추론을 확인했습니다.
사진별 규칙은 검증 분할에서 정하고 최종 시험을 보고 조정하지 않습니다.
무라 전용 모델은 기본 과정이 완성된 뒤 필요성을 판단합니다. 실시간 생산 검사·수율 개선 주장은 범위 밖입니다.

## 현재 완료 범위

정상·단일 5종·복합 짝 데이터 7,000장과 픽셀 마스크를 만들고 두 모델을 각각 16 epoch 학습했습니다.
원본 가족 단위 700/150/150 분할을 유지하고, 전체 장면 검증으로 모델과 후처리를 선택했습니다.
선택 결과와 가중치·추론 코드 해시를 고정한 뒤 시험 1,050장을 평가합니다.
검증에서 선택한 U-Net으로 맥 앱 v0.4를 교체했습니다. 현재 상태·결과와 재현 명령은
[모델 비교 보고서](native-comparison.md)에 기록합니다.

다음 단계는 어두운 회색의 약한 색 이상점과 영역 저하를 닮은 합성 예시를 늘리고,
별도 합성 시험에서 미검출과 정상 오탐을 다시 측정하는 것입니다. 실제 촬영은 프로젝트의 검증 범위에 포함하지 않습니다.
