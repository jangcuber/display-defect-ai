# 한 달 개발 계획

리더가 전체 과정을 먼저 완성하고 팀원에게 실행 가능한 템플릿을 제공합니다.

| 기간 | 작업 | 완료 기준 |
|---|---|---|
| 1주 | 정상·점·선 생성, 라벨·분할 검증, 실제 정상 사진 조건 조사 | 작은 데이터, 사각형 미리보기, 생성 조건과 인계 |
| 2주 | OpenCV 정렬·전처리와 규칙 비교 기준, YOLO26n 작은 학습 | 같은 분할에서 학습/추론 재현, 버전·가중치 출처 기록 |
| 3주 | 맥 단일 사진 검사와 사진별 결과 종합 규칙 | 박스·클래스·점수 표시, 실패 안내, 검증 자료로 임계값 결정 |
| 4주 | 고정 시험 평가·오류 분석·팀원 템플릿 | 클래스별 검출 지표, 사진별 오탐/미탐, 재현 명령 |

합성 시험 성적과 실제 사진 성적은 따로 보고합니다. 실제 시험 자료가 없으면 실제 성능은 미검증입니다.
YOLO26n 패키지 지원·가중치 접근·맥 실행 가능성은 학습 세션에서 확인합니다.
사진별 규칙은 검증 분할에서 정하고 최종 시험을 보고 조정하지 않습니다.
무라 전용 모델은 기본 과정이 완성된 뒤 필요성을 판단합니다. 실시간 생산 검사·수율 개선 주장은 범위 밖입니다.
