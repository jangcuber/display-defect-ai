# 데이터와 정직한 평가

현재 취득한 데이터가 없습니다. 이 문서는 앞으로의 체크리스트이며 완료된 실험 기록이 아닙니다.

[후보 데이터 조사와 평가 설계 제안](data/feasibility-and-evaluation.ko.md)에서 AnoLCD/MSD/MVTec의
접근·이용 조건 미확인 사항, 공식 test 격리, 분할·보정 제안을 확인할 수 있습니다.
제안 수량과 오탐 목표는 아직 채택된 성공 기준이 아닙니다.

## 확보 전에 기록할 것

- 제공자/원본 출처, 이용·학습·재배포 권한, 다운로드 조건과 승인 담당자
- 디스플레이 종류, 촬영 조건, 해상도/채널, 실제 목표 결함, 정상/이상 이미지 수
- 장치/패널/촬영 세션 식별자, 중복/거의 중복 여부, 개인정보 포함 여부
- CPU/GPU, 사용 가능 RAM/VRAM, 저장 공간, 학습 가능 시간

실제 데이터는 git에서 제외한 `data/`, 모델은 `artifacts/`, 결과는 `outputs/`에 로컬로 둡니다.
공개 저장소에 실제 파일이나 민감한 경로/식별자를 올리지 않습니다. 제한된 데이터는 임의 다운로드하지 않습니다.

## 분할과 기록

정상 이미지만 train에 사용합니다. 별도 validation으로 전처리 선택과 임계값을 정하고
test는 마지막 평가까지 잠급니다. 같은 패널/촬영 세션/유사 이미지가 여러 분할에 섞이지 않도록
그룹 단위로 나눕니다. 작은 데이터에 기계적으로 비율을 적용하지 말고 분할별 정상/이상 수를 보고합니다.
로컬 manifest에는 image_id, 상대 경로, split, label(없으면 unknown), group_id,
파일 해시, 출처/권한 기록 참조를 보관합니다. test 라벨을 보고 모델이나 임계값을 고르지 않습니다.

실행 기록에는 baseline 구현/버전, 시드, 전처리, 학습 분할 ID/해시, 모델 가중치 해시,
연산 장치, 학습/추론 시간, 보정 방법/분할 ID/임계값을 남깁니다. 예측 점수와 라벨을
보존해 수치를 재계산할 수 있게 합니다. 데이터 공개가 불가하면 재현의 그 한계도 씁니다.

## 평가 보고 최소 항목

- 정상/이상 표본 수와 장치/촬영 그룹 수, 분할 방법, 대표 실패 사례
- 고정 임계값에서 혼동행렬(TP/FP/TN/FN), precision/recall, 정상 오탐률
- 두 클래스가 모두 있을 때만 이미지 수준 AUROC 등 순위 지표 계산
- 픽셀 정답 마스크가 있을 때만 위치 성능 수치 계산; 없으면 히트맵은 정성 예시
- 작은 표본의 불확실성, 촬영 조건 변화와 새로운 결함 유형에 대한 미검증 범위

분모가 0인 지표는 0점/100점으로 꾸미지 말고 계산 불가로 표시합니다. 정상 validation만으로
보정했다면 정상 오탐 기준을 기록하고 결함 recall을 검증했다고 주장하지 않습니다.
불량 확률, 공장 적용 가능성, 생산 성능은 이번 스모크 테스트로 알 수 없습니다.
